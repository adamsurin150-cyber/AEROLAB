# AeroCalc
Hello!
So Aerocalc is python 'tool' that calculates: lift, drag, weight and a lot of other things. It calculates it for 5 different aircraft: F-16, Cessna, Ask 21(glider)
L-39 and Boeing 737 which for some you can choose different loadouts! (Its not that accurate but that wasnt the main point so its allright for me)

Its written entirely in python with the program VScode

I build it step by step adding thing by thing 
I had a lot of trouble setting everything up, and a lot of syntax errors like forgetting : or ==,...
Im total begginer with graphs so i struggled there 

How to run it ?
1. I would recommend this way:
2. Look for Releases (on the right side of repository)
3. Click on it and download Final_version.exe
4. Double click it to run it in your terminal
5. MINIMALIZE THE GRAPH TO SEE RESULTS (i tried to fix it, but i just cant (spent quite a lot of time on it))
